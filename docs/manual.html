1. このツールでできること

MS2026 の背景（建物・床・小物・ライブ会場のトラスなど）を、Unity と Maya を行き来して作るためのツールです。流れは次の 5 つです。

  1. Unity で、仮の箱だけで作った地図（グレーボックス）を FBX ファイルとして書き出す。
  2. Maya でそのグレーボックスを読み込み、「型紙」として見ながら本物の背景モデルを作る。
  3. 名前のルールに沿ってモデルに名前を付け、Check で間違いを調べる。
  4. Export Block で区画ごとの FBX（と当たり判定のデータ）を書き出す。
  5. Unity で Import Background を実行すると、背景が地図に入る。

このほかに、ライブ会場用の鉄骨（トラス）を数値入力で自動生成する「トラス生成」もあります。

FBX は 3D モデルを渡すためのファイル形式です（Maya と Unity の間の受け渡しに使います）。

2. はじめに

2.1 メニューの場所

Maya 画面の一番上にあるメニューバーに Tools があります。その中の MS2026 にこのツールの項目が並びます（Tools > MS2026）。

メニュー項目内容
グレーボックス...グレーボックス用の作業ウィンドウを開く
フォルダ設定...同じウィンドウを開く（先頭の「0. フォルダ」で設定する）
トラス生成...トラス生成ウィンドウを開く
シェルフを作成ボタンを並べたシェルフ（画面上部のボタン帯）を作る。任意
マニュアルこのマニュアルをブラウザで開く（グレーボックス・トラス生成の各ウィンドウにも マニュアル ボタンがあります）
ツールをリロードツールを読み込み直す（2.3 参照）
Tools > MS2026 が見当たらないときは、まだメニューが作られていません。「6. 困ったとき」を見てください。

2.2 ウィンドウの開き方

  1. メニューバーの Tools をクリックする。
  2. MS2026 にカーソルを合わせる。
  3. 開きたい項目（グレーボックス... か トラス生成...）をクリックする。

ウィンドウは開いたままにしておけます。作業の結果は、ウィンドウ一番下の 状態行（「待機中」と書いてある行）に出ます。うまくいかないときは、まずここを読んでください。詳しい内容は Maya の スクリプトエディタ（メッセージ表示窓）にも出ます。エラーのときは「エラー: …」と出ます。

2.3 「ツールをリロード」の意味と押すタイミング

「リロード」は、ツールのプログラムを読み込み直すことです。Maya を終了して起動し直さなくても、新しい版のツールに切り替わります。

  • 押す場所は 3 か所あります。メニューの Tools > MS2026 > ツールをリロード、またはグレーボックス・トラス生成の各ウィンドウの リロード ボタンです。どれも同じ動きです。
  • 押すタイミング: ツールを更新（T-Drive での更新など）した直後、新しいメニューやボタンが出ないとき、ツールの動きがおかしいとき。
  • 押すと開いていたウィンドウは一度閉じて開き直されます。入力中の欄は初期値に戻ることがあります。
  • トラスのプレビュー（黄色の線）もリロードで消えます。

2.4 単位は cm

このツールの数値はすべて cm（センチメートル） です。Unity の 1 m は Maya の 100 cm にあたります。たとえば「幅 600」は 6 m です。Setup ボタン（3.2）で Maya の単位が cm、上方向が Y に設定されます。

3. グレーボックス

Tools > MS2026 > グレーボックス... のウィンドウで行います。ウィンドウは上から順に、0. フォルダ、1. 準備、2. グレーボックス読み込み、区画の表示、命名（選んでから押す）、3. 検査と書き出し、4. 小物 の枠が縦に並びます。枠の見出しをクリックすると開閉できます。

3.1 フォルダ設定（0. フォルダ）

Maya と Unity はファイルを置き合って受け渡しします。その置き場所（フォルダ）が 3 つあります。

欄使い道既定の場所（MayaWork の下）
グレーボックス FBXUnity が書き出した型紙を読み込む場所Export
区画 FBX などの出力先Export Block の書き出し先Import
小物 FBX ライブラリ小物の保存・読み込み場所Props
  1. 欄にフォルダのパスを入力するか、横の 参照... ボタンでフォルダを選ぶ。
  2. 選んだ時点で自動的に保存され、下の FBX 一覧も更新される。
  3. 元に戻したいときは 既定に戻す を押す。
重要: Unity 側の Tools > MS2026 > Map > Exchange Folders... と、必ず同じフォルダにしてください。違うと、Unity が書いた FBX が Maya に出ず、Maya が書いた FBX も Unity に届きません。迷ったら、MS2026 のプロジェクトにある MayaWork フォルダに Maya 側を向けるのが簡単です。

設定はユーザーごとに Maya に保存され、再起動しても残ります。

3.2 作業の流れ（手順）

  1. Unity で Tools > MS2026 > Map > Export Greybox (FBX) を実行する。Export フォルダに Greybox_...fbx ができる。
  2. Maya のグレーボックスウィンドウで、1. 準備 の Setup を押す（単位 cm・Y 上・表示レイヤーが作られる）。
  3. 2. グレーボックス読み込み の一覧（新しい順）から読み込みたい FBX をクリックして選ぶ（複数選択も可）。一覧が古いときは 更新 を押す。
  4. 選択したFBXを読み込む を押す。一覧に無いファイルは ファイルを選ぶ... から選ぶ。
  5. 「区画の表示」枠の一覧で、作業する区画（エリア）をクリックして選ぶ。
  6. 選択した区画の作業グループ SM_Bg_ を作る を押す。SM_Bg_<区画名> という空の入れ物（グループ）ができる。
  7. アウトライナー（5.6）で、このグループの中に背景モデルを作る。名前は 3.4 の規則に従う。
  8. 書き出す前に、グループを選んで ヒストリを削除（選択以下） を押す。
  9. 最上位のグループ SM_Bg_<区画名> を選んで Check を押す。
  10. 問題が無ければ Export Block を押す。
  11. Unity で Tools > MS2026 > Map > Import Background を実行する。

3.3 読み込んだグレーボックスの扱い

  • 読み込んだ型紙は 区画 ごとに専用の表示レイヤー（GB_<区画名>）に入ります。区画は、地図を分けた 1 エリアのことです。レイヤーは、まとめて表示・非表示を切り替える仕組みです。
  • 型紙は参照用で、動かしたり編集したりしてはいけません（触れない表示になっています）。
  • 同じ区画をもう一度読み込むと、前回分は自動で置き換わります。
  • 「区画の表示」枠: 選択だけ表示（選んだ区画だけ見せる）、すべて表示、すべて非表示、一覧を更新。
  • グレーボックスを半透明 で型紙が透けて見え、自作モデルとの比較がしやすくなります。不透明に戻す で元に戻ります。自作モデルは変わりません。

3.4 命名規則

モデルの名前の先頭（接頭辞）で、Unity 側が「描画するか」「当たり判定を付けるか」を決めます。名前には英数字と _ だけを使い、日本語・空白・記号は使いません。

名前意味向いているもの
SM_Bg_<区画名>区画の最上位グループの名前。区画名はグレーボックスのグループ名と同じにするグループ 1 つだけ
SM_<内容>描画する + モデルの形どおりの当たり判定床・壁・坂など、形の正確さが要るもの
SC_<内容>描画する + 簡易当たり判定（箱・球・カプセルのどれかを Export Block が自動で選ぶ）柱・装飾・小物など。迷ったらこれ
UCX_<元のメッシュ名>当たり判定だけ（描画しない）見た目は細かいが、当たり判定は簡単な形にしたいとき
  • 「当たり判定なし」という名前は無くなりました。旧 NC_ は Check が警告し、自動修正で SC_ になります。
  • 最上位グループ SM_Bg_<区画名> は、位置を原点（0, 0, 0）、回転 0、拡大縮小 1 のままにします。 中のモデルの位置は自由です。
  • 同じ形を何度も使うときは インスタンス（元と形を共有するコピー）が向きます。Maya では 編集 > 特殊な複製 > インスタンス。

命名ボタン（名前を覚えなくてよい）

「命名（選んでから押す）」枠は、オブジェクトを選んでからボタンを押すだけで名前を付けてくれます。

ボタン動き
形どおり (SM_) / 簡易当たり判定 (SC_) / 当たり判定専用 (UCX_)選択したものに接頭辞を付ける。日本語・空白・記号は _ に直る
小物にする: 形どおりの当たり判定 (SM_Prop_) / 小物にする: 簡易当たり判定 (SC_Prop_)選んだ最上位のものを小物の名前にする
名前を自動修正 (選択以下)規則に合わない名前を直す。接頭辞が無ければ SM_ を付ける
問題のノードを選択Check で引っかかったものを選択状態にする

3.5 Check（検査）と Export Block（書き出し）

  1. アウトライナーで最上位グループ SM_Bg_<区画名> をクリックして選ぶ。
  2. Check を押す。名前の間違い、最上位グループの位置ずれ、ヒストリの残りなどが調べられる。
  3. 状態行に「Check: 問題 N 件（スクリプトエディタ参照）」と出る。詳細はスクリプトエディタに出る（問題が無ければ [MS2026 check] OK）。
  4. 問題があれば 名前を自動修正 (選択以下) や 問題のノードを選択 で直し、もう一度 Check を押す。
  5. 問題が 0 件になったら Export Block を押す。

書き出し先（「出力先:」の表示）に、次のファイルができます。

  • SM_Bg_<区画名>.fbx: 区画のモデル
  • SM_Bg_<区画名>.colliders.json: SC_ がある場合の、簡易当たり判定の形（箱・球・カプセル）。状態行に 簡易当たり判定 N 件 (Box a / Sphere b / Capsule c) と出る
  • SM_Bg_<区画名>.props.json: 小物を置いた場合の配置データ

内訳がおかしいときは、スクリプトエディタの [MS2026 collision] の行で、どのモデルがどの形になったか確認できます。

使えない形（NURBS・サブディビジョン）

Unity が読めるのは ポリゴン（三角形・四角形の面でできたモデル）だけです。NURBS（曲面）、カーブ、サブディビジョンは書き出しで黙って落ちます。Check は Not a polygon mesh と警告します。NURBS の面は NURBS をポリゴンに変換（選択以下） でまとめてポリゴンにできます。カーブは変換できないので、消すかポリゴンで作り直してください。

3.6 小物（Prop）

街灯・ベンチなど、何度も使う部品を 小物 と呼びます。小物は区画の FBX に入れず、「小物のモデル」と「どこに置いたかのデータ」を別々に Unity へ渡します。名前は SC_Prop_<名前>（簡易当たり判定。おすすめ）か SM_Prop_<名前>（形どおり）。<名前> は英数字と _ です。

小物を登録する（手早い方法）

  1. 小物のモデルを作る。足元（地面に接する点）が原点になるようにしておく。
  2. 拡大縮小をしたなら、メニュー 修正 > トランスフォームのフリーズ を実行する。
  3. アウトライナーでそのモデルをクリックして選ぶ。
  4. 「4. 小物」枠の 選択を小物として登録（簡易当たり判定・おすすめ） を押す（形どおりにしたいときは 選択を小物として登録（形どおりの当たり判定））。

名前が自動で SC_Prop_... に変わり、Props フォルダに Prop_<名前>.fbx が書き出されます。元のモデルは元の位置に「最初の配置」として残ります。

小物を置く・増やす

  1. 区画グループ SM_Bg_<区画名> をクリックして選ぶ。
  2. 「4. 小物」枠の一覧から置きたい小物を選び、選択した小物を配置 を押す（何度でも置ける。一覧が古いときは 一覧を更新）。
  3. 置いた小物を W で動かす。
  4. 増やすときは Ctrl+D（複製）かインスタンスを使う。どちらも小物として数えられる。
  5. Export Block を押すと、区画 FBX と同時に配置データ .props.json が出る。

Unity 側では、小物の FBX は Tools > MS2026 > Map > Import Props、区画は Import Background で取り込みます。小物の中の名前は Check の対象外です。

登録を使わずに、作ったモデルを選んで 選択を小物として書き出す を押して Prop_<名前>.fbx だけを書き出すこともできます。

4. トラス生成

トラスは、ライブ会場の照明を吊る骨組みで、細い鉄の棒を組んだ四角い柱（4 本の弦を横桟と斜材でつないだもの）です。このツールは、数値を入れるだけでこれを自動で作ります。Tools > MS2026 > トラス生成... で開きます。単位は cm です。

4.1 3 ステップ

  1. 寸法を入れる。 ウィンドウの 種類 を選び、長さ・幅・高さなどを入れる。入れるたびにシーンに黄色の線が出る。
  2. 黄色のプレビューを確認する。 黄色の線は部材（棒 1 本分）の中心線、各線の始点にある正方形は断面（棒を輪切りにした形）。大きさがおかしければ寸法を直す。
  3. 生成 を押す。

形を変えたいときは、生成のあとに「4.5 形を直す」を行います。

生成先は次のとおりです（生成後、状態行に「生成: …（生成先: …）」と出ます）。

  • SM_Bg_<区画>（またはその中のもの）を選んでいれば、その区画の中に作る。Export Block でそのまま当たり判定つきで書き出せる。
  • それ以外のオブジェクトを選んでいれば、その中に作る。
  • 何も選んでいなければ、一番上に作る。後から SM_Bg_ の中へ入れても書き出せる。

名前は 名前 欄に入れます。できるものは SM_Truss_<名前> というグループで、その中に SC_Truss_<名前> の部材が入ります。

プリセット（設定の保存）

ウィンドウの一番上の プリセット 行で、入力欄の組み合わせを名前を付けて残せます。

  • 読み込み: メニューで選んだプリセットの値が、全部の入力欄に入ります
  • 保存...: 名前を聞かれるので入力して OK。今の入力欄がまるごと保存されます（同じ名前は上書き）
  • 削除: 自分で保存したものを消します。最初から入っている「標準 30cm 門型」「大型 50cm 門型」「円形リング R300」「塔 400」は消せません（ステータスに「組み込みプリセットは削除できません」と出ます）

保存した内容はこのパソコンの Maya の設定に入るので、Maya を閉じても残ります。

4.3 種類と向いている場面

種類入れるもの向いている場面
直線長さ。原点は部材の中心まっすぐな 1 本。天井から吊る横棒など
門型幅（柱の外側どうし）、高さ（梁の上端）。原点は床の中央ステージの左右に柱が立ち、上に梁が渡る形（柱 2 本 + 梁 1 本）
パス（カーブから）先に Maya でカーブを 1 本作って選ぶ。部材長（パス）、閉じる（パス・点から）自由な形、曲線。角のあるカーブはそのまま角になり、滑らかなカーブは部材長（パス）（既定 200）ごとに区切られる。輪にしたいときは閉じる（パス・点から）
形プリセット形（プリセット）（直線 / L 字 / コの字 / ロの字）、平面（プリセット）、幅、高さ直角の形を手早く作りたいとき。いちばん簡単
選択した点からロケータ（5.7）を、つなぎたい順に 2 個以上選ぶ置いた点を順に結びたいとき
円弧 / 円半径（円弧）、角度（円弧。360 = 円）、部材長（パス・円弧）、平面（プリセット）丸いトラス。角度 360 で円形のリング、180 で半円のアーチ。平面を 床面 XZ にすると床に寝かせたリング、立面 XY にすると立てたアーチ（アーチの両端は床に乗る）
塔（グランドサポート）高さ（門型・プリセット・塔）、幅（門型・プリセット・塔のベース）（= ベースの一辺、既定 100）床から立つ 1 本の柱。足元に四角いベース板、柱の上端にスリーブ（太いカバー）が付く。ライトやスピーカーの支柱に
  • 平面（プリセット）: 立面 XY は壁のように立てた形（床に乗る）。床面 XZ は床に寝かせた形。
  • 「選択した点から」で使ったロケータは、生成後は消して構いません。
  • 曲がり角では部材どうしが少し重なります。断面より短い区間は作られません（本数がスクリプトエディタに出ます）。
  • 円弧 / 円は丸い線を、部材長ごとの短い直線でつないで近似します（半径 300・部材長 200 の円なら 9 本）。できたものは「パス」と同じなので、5 章の編集用の点でそのまま形を直せます。
  • 塔は、グループの中に柱（SC_Truss_<名前>_Post）とベース板（SC_Truss_<名前>_Base）の 2 つができます。塔はパスには変換できません。
  • 角にブロックを置く（既定 ON）: 門型・パス・円弧の曲がり角に、断面と同じ大きさの四角いブロックを足して、角のすき間をふさぎます。部材の数や当たり判定の箱の数は増えません。切ると従来どおりになります。

4.4 スナップ（形を整える機能）

スナップは、手で入れたり動かしたりした点を、決まった角度・目盛りにそろえる機能です。パス・形プリセット・選択した点からで効きます。

項目意味
スナップ角度（パス系）: 自動（ポリライン 90°・曲線はなし）角のあるカーブ・プリセット・点は 90°、滑らかなカーブは角度なし（グリッドだけ）
なし角度をそろえない
45°横・縦・奥行きと、斜め 45° の方向だけに許す
90°横・縦・奥行きの方向だけに許す（直角）
グリッド cm（0 = なし）長さをこの値の倍数に丸める。既定 10。0 でグリッドなし

先頭の点は動かさず、そこから順に各区間を最も近い許される方向に直します。設定はトラスに保存され、選択したトラスを再生成 でも効きます。

4.5 形を直す（編集用の点）

作ったトラスの形は、編集用の点（黄色い十字のロケータ）を動かして直せます。点は部材の角に出ます。

  1. 直したいトラスをアウトライナーでクリックして選ぶ。
  2. 編集用の点を表示 を押す。角に黄色い十字（ロケータ）が出る。
  3. 動かしたい点の十字をクリックして選ぶ。
  4. W キーを押して移動ツールにし、矢印をドラッグして動かす。
  5. グリッドに合わせたいときは、ドラッグ中に X キーを押しっぱなしにする。
  6. 点を増やすときは、増やしたい位置の手前の点を選び、選択した点の後ろに点を追加 を押す（選んだ点と次の点の中点に出る）。出た新しい点を手順 4 のように動かす。
  7. 点を減らすときは、その点を選び、選択した点を削除 を押す（点は 2 個以上残ります）。
  8. トラスのグループをもう一度選び、選択したトラスを再生成 を押す。形が反映される。
  9. 終わったら 編集用の点を消す を押す。
  • 直線と門型も、編集用の点を表示 でそのまま編集できます。
  • 黄色い十字が見えないときは、視点を引くか、F キーで選択物にフォーカスしてください。
再生成すると、トラスの中で手で直した部分（部材の移動・回転・削除・追加）は消えます。 形の変更は、先に点を直してから再生成してください。再生成してもトラス全体の位置と回転は保たれます。

そのほか: パスに変換（直線・門型 → パス） は、直線・門型を、点で形を持つ「パス」に作り直します。門型は梁が柱の中心線どうしを結ぶ形に変わり、角で部材が重なります。すでにパスのトラスには「すでにパスです」と出ます。

4.6 コライダー（当たり判定）の考え方

コライダーは、ゲームの中でキャラクターがぶつかる見えない壁です。トラスは中が空洞ですが、ゲームでは中に入れません。そのため次のようにします。

  • 部材 1 本 = 当たり判定の箱 1 つ。 弦・横桟・斜材は 1 つのモデルにまとまり、部材ごとに箱（Box）が 1 つ付く。
  • 門型は柱 2 本 + 梁 1 本の 3 つの箱が「コの字」になる。コの字の内側は通れるが、トラスの内部には入れない。
  • この箱は Export Block が .colliders.json に書き出す。
  • 箱の大きさは正確です。 斜材・横桟の端がはみ出さないように切り揃えてあるので、長さ 400 の柱なら箱は 400 × 30 × 30（誤差 1 cm 以内）です。
  • 角ブロックは、角にある部材のモデルに合体します。箱は 1 つのままですが、ブロックのぶんだけ角の方向に少し（断面の半分 = 15 cm）大きくなります。
  • 塔は柱（スリーブ込み）とベース板の 2 つの箱になります。

4.7 プレビューの注意と Undo

  • 黄色の線は MS2026_TrussPreviewGrp という名前で、選択できません。Check や Export Block の対象にもなりません。
  • 生成 を押す、プレビュー表示を OFF にする、ウィンドウを閉じる、リロードする、のどれかで消えます。
  • 寸法が不正（断面以下の数値、カーブや点が未選択など）のときは、線が消えて状態行に「プレビューなし: …」と理由が出ます。
  • Undo（Ctrl+Z）: 生成・再生成・パスに変換などは、1 回押すと 1 操作が戻ります。プレビューの出し入れは Undo の履歴に入りません。
リロード ボタンもこのウィンドウにあります。意味は 2.3 のとおりです。

5. Maya の基本操作（最低限）

5.1 選択

  • モデルを左クリックで選ぶ。選ばれたものは緑（または水色）に光る。
  • Shift を押しながらクリックすると、選択に追加（または外す）。
  • 何もない所をクリックすると選択が解除される。
  • アウトライナー（5.6）で名前をクリックして選んでもよい。

5.2 動かす・回す・拡大縮小

キーツール使い方
W移動矢印をドラッグ
E回転輪をドラッグ
R拡大縮小四角をドラッグ
Q選択ツールを切って選ぶだけに戻る

ツールが効かないときは、先に動かしたいものを選んでいるか確認してください。

5.3 グリッド吸着

移動中に X キーを押しっぱなしにすると、目盛り（グリッド）にぴったり吸い付きます。キーを離すと解除されます。

5.4 視点の操作

  • Alt + 左ドラッグ: 回り込む
  • Alt + 中ボタンドラッグ: 画面をずらす
  • Alt + 右ドラッグ（またはホイール）: 近づく・離れる
  • F: 選択したものにフォーカス（見失ったときの最初の一手）
  • A: すべてが入るように表示

5.5 元に戻す

Ctrl+Z で 1 つ前に戻ります。やり直しは Ctrl+Y（または Shift+Z）です。

5.6 アウトライナーの見方

アウトライナーは、シーンのものを名前の一覧（階層）で見る窓です。メニュー ウィンドウ > アウトライナ で開きます。

  • 名前の左の小さな矢印（▶）をクリックすると、グループの中身が開閉する。
  • 名前をクリックすると、そのものが選択される。ドラッグして別のグループの上に落とすと、中へ移せる。
  • 名前をダブルクリックすると、名前を変えられる。
  • このツールでは SM_Bg_<区画名> の中に背景を作る。画面で選びにくいものも、ここから選べる。

5.7 ロケータ

ロケータは、位置を示すだけの印（十字）です。何も描画されません。メニュー 作成 > ロケータ で作れ、トラスの「選択した点から」と「編集用の点」で使います。
